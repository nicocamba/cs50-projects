# CS50 Projects

A collection of coursework and small projects developed while studying CS50. Projects are grouped by their primary language; web applications and front-end projects live under **Web**, with their implementation languages noted in their own folder.

## Project groups

- [C](C/README.md): command-line programs, algorithms, image processing, and data structures.
- [Python](Python/README.md): scripting, data processing, and simulation exercises.
- [SQL](SQL/README.md): database query exercises and investigative problems.
- [Web](Web/README.md): Flask applications and browser-based projects using Python, HTML, CSS, and JavaScript.

## Running projects

Each exercise may have its own setup requirements and may depend on CS50-provided data or libraries. See the relevant project folder before running it. Flask projects list their dependencies locally.

## Notes

This repository preserves the coursework projects while removing answer-only files and duplicate working copies. The Galicia route-finding final project has its own repository: [cs50-final-project-dijkstra](https://github.com/nicocamba/cs50-final-project-dijkstra).
